# How to make a B42 map / building / basement

> Source: 06_WORLD_MAP_BASEMENTS_TILES.md (compiled 2026-07-29, verified against Project Zomboid 42.20). Imported 2026-09-29. Confidence tags in the text are the original author's.

### 8.1 A B42 map (overview, LIKELY where noted)
1. Install a community fork -- **Crater's Community Edition** (direct B42 fork) or
   **Alree's tools**. **CONFIRMED** these are the options.
2. Extract packed tilesheets if your fork requires it so editors render correctly.
3. Optionally start from the **vanilla map export** (`PZ_Vanilla_map_b42`) as a
   base/reference. **CONFIRMED** it exists.
4. Lay out cells **on the 300x300 editing grid**; the tools export **256x256**
   cells with empty borders. Mind adjacency clashes. **CONFIRMED** (Mapping).
5. Author buildings/lots and RoomDefs (see 8.2); reconstruct `objects.lua` (car
   spawns + navigation meshes -- section 9.3).
6. Generate the in-game map image / thumbnails.
7. Export the map folder (section 9.1) and package with your `mod.info`
   (`pack=` / `tiledef=` -- section 5.3).

### 8.2 A building (CONFIRMED path)
- In **TileZed -> Tools -> Building Editor** -> **New Building** (BuildingEd is
  merged into TileZed).
- **Check the room-definition list first** (pzwiki: Room definitions and item
  spawns, revid 1392885 -- an autogenerated Room -> Containers reference), then
  draw rooms and assign correct RoomDefs so item/zombie spawns are right.
- Multi-Z: author floors above and below as needed.
- Export as the building binary/`.tbx` consumed by the map.

### 8.3 A basement -- CONFIRMED exact steps (pzwiki: Creating basements, revid 1301995)
Two methods: a standalone `.tbx`, or drawn into your `building.tbx`. Guide covers
the standalone method.

**Create the basement:**
1. TileZed -> Tools -> **Building Editor** -> **New Building**.
2. **Check the room list/definitions first** so rooms get correct RoomDefs.
3. In **iso mode**, use **Draw Room** to draw the basement on **floor 1/1**, fully
   enclosed. For multiple levels, add more floors -- **the topmost floor is the
   first floor descending into the basement**.
4. Use **Place Stairs** to put a staircase for entry. Save the `.tbx`.

**Prepare placement:**
5. Open your map project in TileZed, pick the entrance location.
6. With the **BMP Eraser** tool, delete **3 ground-floor tiles** (these 3 will sit
   directly above the staircase).

**Place it:**
7. Open the project in **WorldEd**, drag the basement `.tbx` into your map.
8. Go to the **"lots" tab** -> **Levels** list. Drag the basement `.tbx` from
   **Level 0 onto Level -1** (or select Level -1 first, then drag). The basement
   appears underground.
9. Drag the basement so the **3 erased tiles are directly above the staircase**.

**Connect to a building:**
10. In the Building Editor, open the house/building `.tbx`, go to **Edit rooms**,
    set the room's **"floor" tile to None**, click OK.
11. In **Tile mode**, open **Tilesets**, search **"flooring"**, select a floor
    tile, ensure the **floor layer** is selected, and **Draw Tile** everywhere
    **except the 3 tiles directly above the staircase**. Save the building `.tbx`.
12. Place the house `.tbx` into WorldEd and line up the 3 missing floor tiles.

For **procedural** basements, additionally export to the binary building file and
register it into the world's basement pool (dev-blog mechanic; matching keys are a
gap -- see 4.3).
